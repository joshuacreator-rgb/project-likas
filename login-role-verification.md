# Login Role Verification

The login chooser now presents the requested account types in a clear operational order: Administrator, Evacuation Center Staff, Responder / Disaster Team, and Citizen. Desktop and mobile previews show that the longer labels wrap cleanly inside the role cards without clipping or horizontal overflow.

The role values remain the existing server-authorized values (`admin`, `staff`, `responder`, and `citizen`). Password login still submits the selected role for server validation, and platform sign-in remains server-authoritative and routes users to the matching workspace. On mobile, role cards stack into full-width tap targets and the primary sign-in action remains visible and readable.
